# Seelenformel · Coiffeur Ayan

Eigenständiger Numerologie-Rechner im Schwarz-Gold-Look (Branding: Coiffeur Ayan).

Aus Name, Geburtsdatum, Geschlecht und Körperziel berechnet die Seite alle neun
Werte (Lebens-, Seelen-, Persönlichkeits-, Schicksals-, Kraft- und Schattenzahl
sowie Persönliches Jahr, Monats- und Geburtstagszahl) exakt nach den
Seelenformel-Regeln und erstellt daraus einen persönlichen Report (Brief,
Körpertyp, Ernährung, Bewegung, Tagesrhythmus, Prophezeiung, Botschaft).

- Logo: `assets/coiffeur-ayan-logo.png`
- Die Berechnung läuft vollständig im Browser – es werden keine Daten gesendet.

`index.html` einfach im Browser öffnen.
