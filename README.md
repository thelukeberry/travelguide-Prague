# travelguide-Prague

Zwei eigenständige Seiten:

- **`loveair_reiseguide_website_full.html`** – LoveAir Reiseguide für Prag 2025
  (Restaurants, Hotels, Clubs, Sehenswürdigkeiten).

- **`seelenformel.html`** – *Seelenformel* (Branding: **Coiffeur Ayan**):
  ein eigenständiger Numerologie-Rechner im Schwarz-Gold-Look.
  Aus Name, Geburtsdatum, Geschlecht und Körperziel berechnet die Seite alle
  neun Werte (Lebens-, Seelen-, Persönlichkeits-, Schicksals-, Kraft- und
  Schattenzahl sowie Persönliches Jahr, Monats- und Geburtstagszahl) exakt
  nach den Seelenformel-Regeln und erstellt daraus einen persönlichen Report
  (Brief, Körpertyp, Ernährung, Bewegung, Tagesrhythmus, Prophezeiung,
  Botschaft).

  Logo: `assets/coiffeur-ayan-logo.png`. Die Berechnung läuft vollständig im
  Browser – es werden keine Daten gesendet. Einfach `seelenformel.html` im
  Browser öffnen.
